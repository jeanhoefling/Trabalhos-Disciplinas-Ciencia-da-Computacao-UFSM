# Maratona de Programação

Repositório destinado aos trabalhos e exercícios desenvolvidos na disciplina **Maratona de Programação**.

A disciplina tem como objetivo a preparação para **programação competitiva**, com foco no desenvolvimento da capacidade de resolver problemas de forma eficiente, utilizando diferentes algoritmos e estruturas de dados.

## Conteúdos

Durante a disciplina são abordados conceitos como:

* Algoritmos e técnicas de resolução de problemas
* Estruturas de dados
* Ordenação e busca
* Recursão
* Grafos
* Análise de complexidade
* Matemática aplicada à programação competitiva
* Técnicas de otimização

Os exercícios e trabalhos são desenvolvidos principalmente em:

* **C**
* **C++**
* **Python**

## Trabalhos

Os trabalhos consistem, em grande parte, na resolução de problemas de programação, com o objetivo de praticar os conteúdos estudados e desenvolver raciocínio lógico, análise de complexidade e implementação de soluções eficientes.

```text
maratona_de_programacao/
├── trabalho1/
├── trabalho2/
├── trabalho3/
└── ...
```

Cada pasta contém os códigos e arquivos relacionados ao respectivo trabalho ou atividade da disciplina.

> **Objetivo:** praticar algoritmos, estruturas de dados e técnicas de programação competitiva por meio da resolução de problemas.
